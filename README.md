# INTERO FEST ’26 — National Level Technical Symposium

> **Sree Sakthi Engineering College** • Department of Computer Science & Engineering  
> **Date**: 31 October 2026 • **Venue**: Ooty Main Road, Karamadai, Coimbatore – 641104

## 🎨 Design & Aesthetic

- **Fixed Theme**: **Midnight Cyber** — Deep space obsidian (`#090A10`), elevated surface cards (`#11131E`), and luminous Neon Cyan (`#06B6D4`) & Electric Violet (`#A855F7`) accents.
- **Original Artwork**: Responsive, animated SVG artwork for each competition with zero external image dependencies.
- **Performance & Motion**: Smooth Framer Motion transitions with full `prefers-reduced-motion` compliance.

---

## 🛠 Tech Stack

- **Framework**: Vite + React
- **Icons**: Lucide React
- **Routing**: React Router
- **Animation**: Framer Motion & CSS3 Keyframes
- **Styling**: Vanilla CSS Design Tokens (Strict WCAG Contrast)
